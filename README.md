## 📖 Overview

**Xntrova Technologies** is an enterprise-grade, high-performance web platform designed to present the services, case studies, and conversion-focused capabilities of Xntrova Technologies — an award-winning digital marketing and technology consultancy based in New Delhi, India.

Built with cutting-edge **Next.js 16 (App Router)**, **React 19**, and **Tailwind CSS v4**, this application delivers lightning-fast load times, flawless responsiveness across all devices, best-in-class technical SEO, and interactive conversion mechanisms (including an interactive ROI Calculator and WhatsApp quick-connect widget).

---

## ✨ Key Features

- ⚡ **Ultra-Fast Performance**: Built on Next.js 16 with Turbopack and static site generation (SSG) for sub-second page loads.
- 🎨 **Modern Aesthetics**: Sleek dark and light accents, glassmorphic UI elements, smooth scroll transitions, and subtle hover animations.
- 📱 **100% Fully Responsive**: Pixel-perfect layout tailored for mobile devices, tablets, and ultra-wide desktop monitors.
- 🔍 **Enterprise SEO & Rich Snippets**:
  - Full OpenGraph and Twitter card integration.
  - JSON-LD Structured Data for `Organization`, `LocalBusiness`, and `WebSite` following Schema.org standards.
- 🧮 **Interactive ROI Calculator**: Enables prospective clients to simulate ad spend, target conversion rates, and estimate their return on marketing investment.
- 💬 **Direct WhatsApp Integration**: Floating action button with pre-configured quick messaging for immediate client onboarding.
- 🛡️ **Comprehensive Sections**:
  - **Dynamic Navigation** with responsive mobile drawer.
  - **Hero Section** with high-converting CTA, trust badges, and key metrics.
  - **Trust Marquee** featuring partner networks and industry social proof.
  - **About Section** detailing agency vision, culture, and credentials.
  - **Comprehensive Services Showcase** with deep dives into SEO, Paid Media, Web Development, and Branding.
  - **Why Choose Us** highlighting differentiators, transparency, and client retention rates.
  - **Social Proof & Testimonials** highlighting verified 4.9★ reviews from Google, Clutch, and Trustpilot.
  - **Collapsible FAQ Accordion** for common client questions.
  - **Contact & Lead Capture Form** with direct phone, email, and location mappings.

## 🚀 Getting Started

Follow these steps to set up and run the project locally.

### Prerequisites

Ensure you have the following installed on your machine:
- **Node.js**: `v18.17.0` or higher (Node.js 20+ recommended)
- **npm**: `v9.0.0` or higher (or `pnpm` / `yarn` / `bun`)
- **Git**

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mauryasapna/xntrova.git
   cd xntrova
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to:
   ```plaintext
   http://localhost:3000
   ```

## 🌐 SEO & Structured Data

The application implements enterprise SEO best practices:
- **Semantic HTML5** structure with a single `h1` and hierarchically organized headings.
- **Dynamic Meta Tags** targeting key high-value keywords in Delhi NCR and global markets.
- **Schema.org Structured Data** formatted as JSON-LD:
  - `Organization` (Name, contact phone, service areas)
  - `LocalBusiness` (Address in Dwarka, New Delhi, rating summary)
  - `WebSite` (Canonical URL and site metadata)
